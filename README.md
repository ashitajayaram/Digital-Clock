# Digital Clock

This is a simple **Digital Clock** application built using **Python** and **Tkinter**. The clock displays the current time in the format `HH:MM:SS AM/PM` and updates in real-time. It is a lightweight and visually appealing digital clock with a basic yet functional design.

## Features
- **Real-time clock**: Displays the current time and updates every second.
- **Graphical User Interface (GUI)**: Built with Tkinter for creating a user-friendly interface.
- **Customizable look**: The clock's font, background, and foreground colors can be easily modified.

## Technologies Used
- **Python**: The programming language used for development.
- **Tkinter**: Python's standard library for creating graphical user interfaces.
- **time module**: Used to fetch the current system time.

## Future Improvements
- **Add alarm functionality**: Allow users to set an alarm time and sound.
- **Time zone support**: Show the time for different time zones.
- **Customizable themes**: Allow users to select different themes or colors for the clock interface.
- **Resizable window**: Make the window resizable while maintaining the clock's proper display.
